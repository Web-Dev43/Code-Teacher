What is HTML?

HTML is the stuff that gives a webpage its structure. Headings, paragraphs, buttons, images. The bones of the site.

LESSON 02 · HTML

Paragraphs: <p>

A paragraph is a normal block of text. In HTML, you wrap your text in <p> and </p> so the browser knows, "this is a paragraph."

<p>This is a paragraph.
<p>You can have another paragraph right after it.

THE PATTERN

<p>This is some text.</p>

<p> opens the paragraph. This is some text. is the content. </p> closes it.

Again: open → content → close.

NOW YOU

Write your own paragraph

Replace the text inside the <p> tags with anything you want, then hit Run code. Try adding a second paragraph too.

Links: <a>

Links let people move around the web. Learn how the <a> tag connects your page to another page or website.

LESSON 03 · HTML

Links: <a>

The <a> tag creates a link. The href attribute tells the browser where the link should go.

<a>Click me
hrefhttps://example.com

THE PATTERN

<a href="https://example.com">Visit Example</a>

<a> opens the link. href says where it goes. Visit Example is what the user clicks. </a> closes it.

Think of href as the link's destination.

NOW YOU

Make your own link

Create an <a> tag with an href and some clickable text. Then hit Run code.
